# Technologies Used

## 1. HTML

HTML is used to create the structure of the PocketSmart AI application.

## 2. CSS

CSS is used to design the application interface, including cards, forms, buttons, tables and dashboard sections.

## 3. JavaScript

JavaScript is used to handle:

- Income calculations
- Expense calculations
- Budget calculations
- Balance calculation
- Transaction display
- Budget recommendations

## 4. Python

Python is used for backend development and recommendation functionality.

## 5. Flask

Flask is used to create the backend API and run the Python web server.

## 6. Recommendation Logic

A rule-based recommendation system compares expenses with the monthly budget and displays appropriate spending recommendations.

## 7. Database Structure

The project defines structures for:

- Income
- Expenses
- Budget
- Transactions

## 8. GitHub

GitHub is used to store and manage the project source code, documentation and project files.

## Conclusion

These technologies are combined to develop the PocketSmart AI budget management application.
