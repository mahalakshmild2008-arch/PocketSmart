# Phase 7 – Project Documentation

## Project Name

PocketSmart AI – Your Smart Budget & Recommendation Assistant

## 1. Introduction

PocketSmart AI is a smart budget and recommendation assistant developed to help users manage their income, expenses and monthly budget.

The application provides a simple dashboard where users can enter income, record expenses, set a monthly budget and receive spending recommendations.

## 2. Problem Statement

Managing daily expenses and monthly budgets manually can be difficult.

PocketSmart AI provides a simple digital solution for recording financial information and monitoring spending.

## 3. Objectives

The main objectives of PocketSmart AI are:

- To record user income.
- To record daily expenses.
- To set a monthly budget.
- To calculate the remaining balance.
- To display recent transactions.
- To provide budget recommendations.
- To help users monitor their spending.

## 4. Main Features

### Income Management

Users can enter their income amount and select the income source.

### Expense Management

Users can enter an expense amount, category and description.

### Monthly Budget

Users can set their monthly spending budget.

### Financial Dashboard

The dashboard displays:

- Total Income
- Total Expenses
- Remaining Balance
- Monthly Budget

### Transaction Tracking

Income and expense transactions are displayed in the Recent Transactions section.

### Recommendation System

The application provides recommendations by comparing expenses with the monthly budget.

## 7. Working Process

1. The user enters income.
2. The user enters expenses.
3. The user sets a monthly budget.
4. The application calculates the remaining balance.
5. Transactions are displayed.
6. Expenses are compared with the budget.
7. A budget recommendation is displayed.

## 9. Conclusion

PocketSmart AI provides a simple way to manage income, expenses and monthly budgets.

The project demonstrates the use of web technologies, Python, Flask and rule-based recommendation logic to develop a budget management application.
