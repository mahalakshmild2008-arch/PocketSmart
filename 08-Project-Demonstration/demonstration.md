# Phase 8 – Project Demonstration

## Project Name

PocketSmart AI – Your Smart Budget & Recommendation Assistant

## 1. Project Introduction

PocketSmart AI is a smart budget and recommendation assistant designed to help users manage their income, expenses and monthly budget.

## 2. Purpose of the Project

The purpose of PocketSmart AI is to provide a simple application for tracking income and expenses, setting a monthly budget and receiving spending recommendations.

## 3. Key Features

- Add income
- Add expenses
- Set monthly budget
- Calculate remaining balance
- View recent transactions
- Display budget recommendations
- User-friendly dashboard

## 4. Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Rule-based recommendation logic

## 5. Project Demonstration

The project demonstration will show the complete working process of PocketSmart AI.

### Step 1 – Open the Application

Open the PocketSmart AI application and display the main dashboard.

### Step 2 – Add Income

Enter an income amount and select the income source.

Example:

Income: ₹20,000

### Step 3 – Add Expense

Enter an expense amount, category and description.

Example:

Expense: ₹2,000

Category: Food

Description: Lunch

### Step 4 – Set Monthly Budget

Set the monthly budget.

Example:

Monthly Budget: ₹10,000

### Step 5 – View Dashboard

Show the following information:

- Total Income
- Total Expenses
- Remaining Balance
- Monthly Budget

### Step 6 – View Transactions

Show the income and expense records in the Recent Transactions section.

### Step 7 – View Recommendation

Show the recommendation generated based on the expenses and monthly budget.

## 6. Benefits

PocketSmart AI helps users:

- Track income
- Monitor expenses
- Manage monthly budgets
- Calculate remaining balance
- Understand spending
- Receive budget recommendations

## 7. Final Output

The final output is a working PocketSmart AI budget management application with a dashboard, transaction tracking and budget recommendation features.
